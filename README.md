# AnLiteBackup

轻量、现代、高效的 Android 应用与数据备份还原工具。

---

## 项目简介

AnLiteBackup 是一款基于 Jetpack Compose 与 Material 3 现代界面设计、以 Restic 为底层增量备份引擎的 Android 本地备份工具。应用专为追求简洁、纯粹与高效还原体验的用户设计，具备全链路 Root 安全探测、全串行任务调度机制以及极速的两阶段应用数据直写能力。

---

## 功能特性

- **应用与数据完整管理**：支持 APK、应用私有数据（`/data/data`）以及设备加密数据（`/data/user_de/0`）的独立或组合备份与还原。
- **两阶段极速直写还原**：还原阶段先进行极简 APK 提取与静默安装，随后直接将私有数据还原至目标目录并自动修正 UID/GID 权限，避免冗余的中间解压拷贝。
- **自定义目录与预设备份**：支持对常用目录（如 Documents、Download、DCIM、Termux 等）以及任意自定义路径进行增量快照备份与原路/重定向还原。
- **自然日期聚合时间轴**：按日期分组清晰展现历史快照流，支持快速查看版本变更、单项/批量还原与快照管理。
- **全串行调度队列与实时进度**：所有备份与还原任务按序严格排队执行，配合顶部动画横幅提供细粒度执行进度，杜绝并发冲突与界面卡死。
- **快照生命周期管理**：支持历史快照快速移除（Forget）与底层存储碎片整理（Prune），即时回收物理磁盘空间。
- **纯粹现代架构**：全响应式 Material 3 单 Activity 架构，无臃肿后台常驻，干净轻量。

## 快速上手

### 运行环境要求
- **系统版本**：Android 8.0 及以上（API Level 26+）
- **权限要求**：已获取 Root 权限（完整兼容 Magisk、KernelSU、APatch）

### 基本使用流程

#### 1. 初始化设置
首次打开应用并授予 Root 权限后，可在「设置」中指定备份存储库路径并设置仓库访问密码。

#### 2. 备份应用或目录
- **应用备份**：在「应用」面板浏览应用列表，支持按用户应用/系统应用/备份状态筛选。可点击单个应用进入详情备份，或长按开启多选通过底部操作栏执行批量备份。
- **目录备份**：在「目录」面板点击添加按钮，选取预设路径（如 Termux、Documents）或手动输入绝对路径，点击卡片即可发起增量备份。

#### 3. 还原数据
- **单项还原**：进入应用或目录详情，在历史快照列表中点击还原，选择需要恢复的组件（APK 与/或 应用数据）。
- **批量还原**：在「应用」页面开启多选并点击「批量还原」，系统将自动匹配已有最新快照并加入串行队列依次执行。
- **目录重定向还原**：在目录详情页可选择「重定向还原」，将快照内容安全恢复至指定的测试或导出路径。

#### 4. 存储库维护与空间回收
在「存储库」面板可按日期浏览全局快照记录。当删除了旧版本快照后，点击右上角的「整理碎片」操作，Restic 引擎将自动清理未引用的底层数据块并释放存储空间。

## 常见问题

### 为什么还原过程比传统工具更快？
AnLiteBackup 采用两阶段直写流水线：在安装完精简 APK 后，数据直接解压写入系统的 `/data/data/<package>` 与 `/data/user_de/0/<package>` 目录，全程无临时文件落地与二次全量复制，IO 消耗降至最低。

### 支持跨设备或刷机后数据恢复吗？
支持。只要备份存储库文件完整且密码正确，在新系统或新设备上安装 AnLiteBackup 并指向该仓库路径，即可直接读取历史快照并恢复全部应用与数据。

### 删除快照后为什么存储占用没有立刻减少？
快照删除（Forget）操作仅移除了快照索引指针。若要彻底回收被删除快照占用的物理存储空间，请在「存储库」页面执行一次「整理碎片」（Prune）操作。
